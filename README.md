Este documento compreende o planejamento geral das atividades a serem realizadas no âmbito do 
projeto 004/2022 para estudos de criminalidade e segurança pública e ordem pública no Município 
de Santa Bárbara, Minas Gerais. Serão apresentadas as diferentes etapas e a forma como elas estarão 
concatenadas ao longo das atividades previstas.
Todas as atividades estão inter-relacionadas e possuem uma grande sinergia que implicará na 
definição da maneira como serão articuladas entre si, bem como o timing necessário para estas 
interações. Apresenta-se, a seguir, o detalhamento de cada atividade.


Os dados originais são restritos ou privados por razões éticas/sigilo.
